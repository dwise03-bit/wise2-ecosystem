# WISE² Web Design System

## Typography
- Display: 56px - Ubuntu Bold
- Heading: 36px - Ubuntu 600
- Body: 18px - Ubuntu 400
- Caption: 14px - Ubuntu Mono

## Layout
- Base unit: 16px
- Gutter: 16px
- Max-width: 1400px
- Spacing scale: 4, 8, 12, 16, 24, 32, 48, 64

## Components
- Hexagonal cards (clip-path)
- Animated buttons
- Status indicators
- Data tables
- Form inputs
